# Four-request gripper-mask separation protocol

This separate development ablation follows the preserved model-only contact failure in [the contact report](CONTACT-RESULTS-20261029.md). It uses the same four already exposed episode-2/3 recordings and all their frozen references. It adds no Spark calls, no new semantic judgments and no new source recordings.

Two source-bound initial boxes identify the visible left and right grippers (track IDs 3 and 4). The boxes include visible palm and fingers, with explicit clipping at the image's left/right boundary; they do not assert that the whole gripper is visible. One bounded SAM video request per clip tracks those reviewed objects. Their native clip SHA, dimensions, PTS, frame map and requested indices must exactly match the retained target response.

The fixed geometry rule is Chebyshev distance between mapped foreground pixel centers: support requires distance **greater than 3 source pixels** to **both** reviewed grippers. Distances 0–3 are exact; capped distance 4 means at least 4, not the true larger separation. Both gripper masks and the target must be nonempty, decoded from the official parser and confidence ≥0.8. Missing/weak/invalid evidence is unavailable, never verified absence. Mapping uses the existing inclusive source-box/nearest-pixel-center rule, with 32-million-pixel and 30-second computation bounds. Limits fail closed.

The geometry module records source/mask hashes and per-gripper evidence. A near or unavailable result removes current-frame eligibility and resets confirmation history. It cannot create a positive semantic result, restore an unscored network request, weaken confidence, change source spacing or bypass a visibility/identity gate. Original v2/v3 observations each feed the original greedy and current-view policies with this additional veto, and are compared with all nine unchanged historical methods. References and later object boxes are scoring-only.

Only **four** new provider attempts are admitted persistently, with zero automatic retries and one execution marker. Video costs use reported processed-frame billing; the estimated $3 allocation is advisory, not a provider dollar limit. Historical and incremental costs remain separate. The code, initial reviews, source bytes, fixed margin, budget, baselines and public plan are frozen and pushed before these calls. Earlier uncertain or failed operations remain intact.

Close estimated masks do not prove physical contact or occlusion. Separate prompts still use the same SAM model, with correlated errors and possible finger undersegmentation. A separation result only supplements an existing clear judgment. This small exposed-data experiment cannot establish independent identity, physical recovery, continuous visibility or cross-domain safety. It does not change live placement acceptance.
