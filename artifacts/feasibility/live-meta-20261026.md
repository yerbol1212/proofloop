## Interpretation

The Spark experiment tests exact-count draft compilation. The SAM experiment separately tests an authored **visibility** protocol. The current bridge supplies positive observations and count lower bounds. It cannot establish complete visibility or absence, so it cannot yet certify the compiler's exact-count drafts. Connecting those contracts without inventing certainty is a remaining implementation gate.

All four images are explicitly generated fixtures with manually defined regions. The two correct images share a generated reference and do not establish temporal stability on a camera. Synthetic timestamps exercise checker integration only. Model confidence is not a calibrated correctness probability.

No person executed a physical correction in this experiment. There is no claim of held-out accuracy, general procedure learning, factory readiness or competitor superiority. The next evidence gate is owned phone footage containing a visible wrong placement, a human correction, fresh verification and an occluded view that stays unknown.

## Reproduce

Install the optional SAM dependency in Python 3.10 or newer, save `META_API_KEY` locally, then run:

```bash
python -m proofloop.smoke --image inputs/synthetic/correct.png --concept screwdriver
python -m proofloop.live_scenes --output artifacts/local/my-new-scene-run
python -m proofloop.compiler \
  --requirements 'Exactly one screwdriver in the left region and exactly one pair of pliers in the right region. These are the only requirements.' \
  --objects screwdriver pliers --regions left right
```

The scene runner makes at most eight new SAM calls with no retries. Raw outputs stay in ignored `artifacts/local/`. Choose a new run directory; `--resume` explicitly reuses matching completed responses and labels them as reused.
